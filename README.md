# Wendell Connects

Portfolio website for T. Wendell Williams III.

This repository contains the static HTML, CSS, JavaScript, and media files for the portfolio. The email address is intentionally omitted; an email correspondence form will be added later.

## Run locally

Open `index.html` in a browser.

## Deploy

The site is a static website with no build step. Import this repository into a static host such as Vercel and use the repository root as the project directory and output directory. The portfolio pages and assets are organized at the root, `work/`, and `assets/`.
